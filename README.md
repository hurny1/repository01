# Repository01

This repository contains various ESP32-based projects.

## Projects

### CYD Camera System
**Location:** `cyd-camera/`

A complete camera system for the CYD (Cheap Yellow Display) with ESP32, featuring:
- Live video streaming
- Web-based camera controls  
- On-device display integration
- HTTP Basic Authentication
- Image capture and storage

[View CYD Camera Project Documentation](cyd-camera/README.md)
