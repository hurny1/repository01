# Project Name

**camera-and-cyd**

## Full Title
Camera and CYD - ESP32 Camera System

## Description
A complete camera system for the CYD (Cheap Yellow Display) with ESP32, featuring:
- Live video streaming
- Web-based camera controls
- On-device display integration
- HTTP Basic Authentication
- Image capture and storage
